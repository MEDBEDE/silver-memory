# Ю.Лист — ПО для вендингового копировального аппарата

Минимальная реализация ядра управления копировальным автоматом:

- расчет стоимости копии (ч/б и цвет);
- поддержка двусторонней печати со скидкой;
- проверка бумаги и тонера перед печатью;
- обработка оплаты (наличные/карта) и расчет сдачи;
- история операций.

## Запуск демо

```bash
python app.py
```

## Тесты

```bash
pytest -q
```
